# 因子报告内容契约

> 状态：**生效**（v2.0，对应 `REPORT_GENERATOR_VERSION = "2.0"`）
> 适用：`lquant.factors.evaluate.report.factor_report` 产出的自包含 HTML 因子报告
> 关联：[因子报告设计评审](因子报告设计评审.md)（R1–R26）、[因子报告内容完备性评估](因子报告内容完备性评估.md)、
> `src/lquant/factors/evaluate/defaults.py`、`tests/unit/test_report_defaults.py`

## 0. 为什么需要这份文档

评审 R20 的结论是：「报告在路线图里被当作关键交付物，但**没有任何地方规定它必须包含什么**」——
R1–R19 里有一大半本质是「缺契约」的后果：没有契约，就无法判断一节该不该出现、
一个数字该用什么单位、三个入口该不该一致。

因此这份文档不是描述性说明，而是**可执行的契约**：

| 契约条款 | 落到哪 |
|---|---|
| 默认口径（组数/衰减阶梯/窗口/成本档） | `lquant/factors/evaluate/defaults.py` 的常量，三入口只许引用 |
| 必须包含的小节 | `factor_report` 的组装表 + 本文 §2 |
| 缺失小节的行为 | §5（跳过条件必须显式，禁止静默） |
| 单位与格式化 | §3（`_fmt` / `_table` 的参数约定） |
| 三入口一致性 | §4 + `tests/unit/test_report_defaults.py` |
| 版本与陈旧判定 | §6（head 里的两个 meta） |

改报告 = 改契约：**先改本文与 `defaults.py`，再改代码**；口径不兼容变化必须递增
`REPORT_GENERATOR_VERSION`（否则旧报告会被误认为新口径，这正是 R15 的坑）。

## 1. 报告的定位

- **单文件、无外部依赖**：不引 CDN / JS / 字体，内联 SVG 现画，能邮件转发、能归档、能离线打开。
- **能自证身份**：三个月后打开，仍能读懂「这是什么因子、在什么数据上、用什么口径算的」。
- **先结论后证据**：第一节是「结论」，不是指标堆。
- **口径统一**：IC 族一律原值、比率一律 `%`、倍数一律 `x`、布尔一律 是/否。
- **不许静默**：算炸了要留痕，截断了要写「仅显示前 N 行（共 M 行）」。
- **涨红跌绿**（A 股习惯）：`#C0392B` 涨 / `#1E8449` 跌；评级徽章不表示涨跌。

## 2. 必须包含的小节

「级别」含义：**MUST** = 无条件输出；**COND** = 条件满足才输出（条件是契约的一部分）。
所有 COND 小节缺失时**不得报错**，也不得静默 —— 见 §5。

| # | 小节 | 级别 | 触发条件 | 缺失时行为 |
|---|---|---|---|---|
| 0 | HTML `<head>`（版本 + 生成时间 meta） | MUST | — | — |
| 1 | 标题与副标题（因子名 · 股票池 · 前瞻收益 · 生成时间 · 版本） | MUST | — | — |
| 2 | **结论**（评级 + 稳健性 + 一句话总结） | COND | 传了 `rating` 或 `robustness` | 整节省略（不是空白节） |
| 3 | **样本与口径**（11 项 kv + 样本过滤表） | MUST | — | 未提供的项写「未提供」，不隐藏行 |
| 4 | **本节生成失败**（故障横幅） | COND | `errors` 非空 | 无故障时不输出 |
| 5 | 样本过滤（|z| 阈值剔除统计） | COND | 传了 `filter_zscore` 或 `outlier_stats` | 省略；口径说明仍在 #3 |
| 6 | 核心指标（IC/RankIC/IR/t 值/正比例/自相关/半衰期/多空…） | MUST | — | 数值不可算时显示 `n/a`，**不留空** |
| 7 | 累计 IC（折线） | MUST | — | 序列为空时图表区为空态 |
| 8 | 滚动窗口（RankIC / IC / IR 三条线 + 表格） | MUST | — | 数据不足时输出「数据不足：滚动指标」 |
| 9 | 分层收益（柱图 + 表） | MUST | — | 组数不足时表为空 |
| 10 | 分层净值曲线 | COND | 有分层净值序列 | 省略 |
| 11 | 超额收益 | COND | `extras["excess"]` | 省略 |
| 12 | Top-N 持仓收缩 | COND | `extras["top_n"]` | 省略 |
| 13 | 事件式分层收益（±N 交易日） | COND | `event_window` 且数据够 | 省略；算炸 → 记 `errors` |
| 14 | IC 衰减（衰减阶梯曲线 + 表） | MUST | — | — |
| 15 | 分年度 IC | MUST | — | — |
| 16 | IC 归因阶梯（原始 → 去极值 → 标准化 → 中性化） | COND | `extras["neutral_ladder"]` | 省略；空 → 记 `errors` |
| 17 | 中性化视图 | COND | `extras["neutral_views"]` | 省略 |
| 18 | 归因分解（暴露 + 收益贡献 + 分组特征） | COND | 存在**分类**维度（见 §7 不变量） | 维度过少/失败 → 记 `errors` |
| 19 | 分组 IC · 行业 | COND | `group_col` 存在且列在帧里 | 省略 |
| 20 | 分组 IC · 市值 | COND | `extras["group_ic_size"]` | 省略 |
| 21 | 风格相关性体检 | COND | `extras["style_corr"]` | 省略 |
| 22 | 换手率（含多空分端） | COND | 帧里有 `symbol` 列 | 省略 |
| 23 | 成本敏感性（决策表） | COND | `bps_list` 非空 | 省略 |
| 24 | 容量与流动性 | COND | `extras["capacity"]` | 省略 |

**组装顺序即阅读顺序**（`factor_report` 的 `body` 列表）：结论 → 身份 → 故障 →
样本过滤 → 核心指标 → 累计 IC → 滚动 → 分层收益 → 净值 → 超额 → Top-N →
事件式 → 衰减 → 分年度 → 归因阶梯 → 中性化视图 → 归因分解 → 分组 IC（行业/市值）
→ 风格 → 换手 → 成本 → 容量。

## 3. 格式化口径（单位即结论）

| 类别 | 例子 | 渲染 | 实现 |
|---|---|---|---|
| IC 族 | `ic_mean`、`rank_ic`、`ir`、`t_stat` | 原值 4 位小数（`0.0091`） | `_fmt(v)` |
| 比率 / 收益率 | `positive_rate`、`win_rate`、`annual_return`、`max_drawdown`、权重、覆盖率 | `12.34%` | `pct=True` |
| 倍数 | `annual_turnover` | `41.9x` | `ratio=True` |
| 布尔 | `viable` | 是 / 否 | `boolean=True` |
| 整数语义 | 年份、期数、组号、`n_days`、`bps` | 不带小数（`2026`，不是 `2026.0000`） | 自动（整数值）或 `int_cols` |
| 缺失 | 任何 `None` / `NaN` | `n/a` | — |
| 日期 | `2026-01-05` | ISO | — |
| 文本 | — | HTML 转义 | `_esc` |

补充约定：

- IC 族**不得**写成百分数，比率**不得**写成小数 —— 同一份报告内同一种量只能有一种写法（R9/R11）。
- 表格里超过 `limit` 行必须写脚注「仅显示前 N 行（共 M 行）」；行数 ≤ `limit` 不写。
- **不设上限**的小节：归因分解、分组 IC（行业/市值）、成本敏感性、容量、Top-N、归因阶梯 ——
  它们的行数由业务维度决定（申万一级 31 个行业），截断会直接误导结论（R8）。
- 列名映射：内部列名不得出现在正文（`cov_industry_sw1` → 申万一级行业，
  `fwd_ret_5` → 5 日前瞻收益，`all` → 全市场）（R14）。

## 4. 三个入口的一致性

三个入口指：CLI `lq factor report`、`POST /factors/evaluate`、`POST /factors/synthesize`。

| 维度 | 契约 |
|---|---|
| 默认分层组数 | `DEFAULT_N_GROUPS = 10`（CLI / API 评价 / API 合成 / 报告 / Web 页面一致） |
| 默认衰减阶梯 | `DEFAULT_DECAY_HORIZONS = (1,2,3,5,10,20,40,60)`，报告与序列**同一条曲线** |
| 默认滚动窗口 | `DEFAULT_WINDOW = 60` 交易日；请求给了 `window` 就必须一路透传到报告的滚动小节 |
| 默认成本档 | `DEFAULT_BPS = (0,5,10,15,30)` |
| 股票池显示 | 统一走 `universe_label()`；缺省 = 全市场（不再出现裸 `all`） |
| 身份披露 | 三个入口都必须传 `display_name` / `expr` / `data_start` / `n_samples` |
| 真实配方 | 报告写**实际执行**的配方。CLI 的 `prepare_segment` 会用默认配方中性化 —— 报告必须如实写，不许写「原始因子直接评价」（R2） |
| 归因/分组 IC/成本 | 合成入口也必须接线（否则合成报告永远比单因子报告薄） |

执行方式：**默认值只允许来自 `defaults.py`**。`tests/unit/test_report_defaults.py`
直接比对各入口的默认值是否 === 常量；在入口处再写一个字面量就会红。

## 5. 缺失与失败的行为

| 情形 | 契约行为 |
|---|---|
| 可选小节的条件不满足（没传 extras / 没有分类列） | **跳过**该节，不报错 |
| 可选小节满足条件但计算抛错 | 捕获 → 写进 `errors` → 顶部渲染「本节生成失败」横幅 + 原因（`类型: 消息`） |
| 核心计算抛错（IC/分层/衰减本身） | **向上抛**：这些算不出来，报告没有意义 |
| 报告生成完全失败（API） | 响应里 `errors["report"]` 记录，其余 metrics 照常返回（报告不是评价的前置） |
| 表格行数超上限 | 保留前 N 行 + 脚注说明总数 |
| 数值不可算 | 渲染 `n/a`，**不是**空白、不是 0 |

「静默消失」被明确禁止：一节要么在报告里，要么在「本节生成失败」里，没有第三种状态。

## 6. 版本与陈旧判定

报告 `<head>` 必须带两个 meta（R15）：

```html
<meta name="lquant-report-generator" content="2.0">
<meta name="lquant-report-generated-at" content="2026-02-01 09:30">
```

- 正文副标题与页脚同样印出版本与生成时间。
- `REPORT_GENERATOR_VERSION` 在**口径或版式不兼容变化**时递增（只改样式不递增）。
- 报告中心 `/factors/reports` 与因子详情用同一判据：
  `stale = meta版本 != 当前 REPORT_GENERATOR_VERSION`。
  **缺版本号 = 版本号引入之前的产物 = 陈旧**（这正是 242 份旧错误报告的分辨依据）。
- 报告文件按因子名覆盖写（不保留历史）。因此 UI 面板叫「报告」，并显式说明「同名覆盖」，
  不再自称「历史报告」（R16）；列表匹配必须是精确路径，不用 `{name}*.html`（R17）。
- 旧口径报告必须能被**识别 → 重算或清理**（失效标记本身不等于修复）：

```bash
lq factor reports                     # 列出全部报告（含版本/生成时间/是否旧口径）
lq factor reports --stale-only        # 只看旧口径
lq factor reports --rebuild-stale     # 重算：按「内嵌表达式 → factor_def.name →
                                      # factor_<canonical_id> 反查」推断表达式，推断不出则跳过并给原因
lq factor reports --prune-stale --yes  # 删除（不加 --yes 只演练）
```

  表达式推断**只认精确来源，绝不猜** —— 猜错等于用错口径覆盖掉一份报告，比留着旧报告更糟。

## 7. 不变量

1. **绝不按 `symbol` 归因**：归因维度必须是分类维度。`cat_col == symbol_col` 时
   报告拒绝输出归因分解并留痕 —— 这条由 `factor_report` 自己守，不靠调用方自觉（R25）。
2. **归因表与表头可对账**：`gross_exposure` 用全部维度求和，展示也不截断。
3. **分组 IC 按 |IC| 降序**：可复现，且重要组不会被截断丢掉。
4. **衰减曲线复用调用方已算好的 `fwd_ret_*`**：行过滤之后补算会跨过被剔除的行，
   把「h 个交易日后的收益」算成更长区间（`decay.py` 有详细说明）。
5. **样本过滤是显式开关**：默认关；开关状态、依据列、是否生效（列缺失时为 `unavailable`）
   都必须在报告里披露。

## 8. 变更流程

1. 改 `defaults.py` / 本文（先说清为什么）。
2. 改 `report.py` 与三个入口的接线。
3. 口径不兼容 → 递增 `REPORT_GENERATOR_VERSION`（旧报告随即被标「旧口径」）。
4. 补测试：`tests/unit/test_report_defaults.py`（默认值同源、版本 meta、陈旧判定、
   身份披露）、`tests/unit/test_report_content_v2.py`（内容块）、
   `tests/unit/test_report_gaps.py`（分支与失败可见）。
5. 回归命令：

```bash
PYTHONPATH=$PWD/src /Users/lyp/code/lquant/.venv/bin/python -m pytest \
  tests/unit/test_report_defaults.py tests/unit/test_report_content_v2.py \
  tests/unit/test_report_gaps.py tests/unit/test_report_enhanced.py -q
```
