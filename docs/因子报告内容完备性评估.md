> 评估时间：2026-10-04
> 评估对象：`factor_report` 生成的 HTML 研究报告的**内容本身**（不评接线/工程缺陷，
> 那部分见同目录 `因子报告设计评审.md`）
> 基线：`main` = `7aa9855`；评估 worktree：`.claude/worktrees/factorreport`（分支 `worktree-factorreport`）
> 样本：`data/reports/BETA10_copy.html`（10-04 新口径 API 报告，12 节全出）+ 244 份历史工件
> 判定基准（四条，缺一不可）：
> 1. **alphalens tear sheet** —— Returns / Information Coefficient / Turnover / Grouped 四大块
>    （[alphalens README](https://raw.githubusercontent.com/quantopian/alphalens/master/README.rst)）
> 2. **券商单因子测试报告惯例** —— 因子定义、样本与预处理、有效性检验、相关性、换手与成本、稳健性、结论
>    （例：[华泰单因子测试系列](https://vip.stock.finance.sina.com.cn/q/go.php/vReport_Show/kind/strategy/rptid/3595389/index.phtml)）
> 3. **本项目自己的契约** —— `docs/FACTOR_VALIDATION.md` 的 L2 判据（分层单调 / IC 衰减 / 收益归因 / **评级** / OOS 衰减）
>    与 L3 判据（参数扰动 / 分段稳定 / 起点敏感 / 月度剔除）
> 4. **平台自己的 Web 页面** —— 同一份数据在 Web 上渲染了什么（内部完备性基准）

## 一、结论

**报告的「因子有效性主线」是完备的，但它缺了三个整类内容；而且它比平台自己的 Web 页面少得多。**

| 内容大类 | 报告覆盖 | 判定 |
|---|---|---|
| A. 因子身份与样本口径 | 1 / 9 | ❌ **整类缺失** —— 报告不知道自己是谁、在什么样本上算的 |
| B. IC 有效性 | 7 / 11 | 🟡 主线齐，缺 IC 自相关、中性化归因阶梯、三视图；滚动只画 1/3 |
| C. 分层与组合 | 6 / 11 | 🟡 主线齐，缺**超额收益体系**、Top-N 收缩、多空 4 项指标 |
| D. 交易与成本 | 2 / 4 | 🟡 缺分端换手；容量分析平台也没做 |
| E. 暴露与相关性 | 2 / 7 | 🟡 缺市值分组 IC、风格相关性；**收益贡献与分组特征算了但没渲染** |
| F. 稳健性与结论 | 1 / 8 | ❌ **整类缺失** —— 报告里没有任何「结论」，而 L2/L3 判据全在这一类 |
| G. 报告可用性 | 2 / 4 | 🟡 自包含 ✅、免责声明 ✅，但错误不可见、无版本 |

**合计 21 / 54**（🟡 按 0.5 计）。缺的不是「锦上添花」，而是三类**结构性**内容：

1. **样本与口径披露（A 类）**：报告不写因子表达式、不写数据区间、不写样本量、
   不写剔除规则、不写预处理配方。读者无法判断「这个 IC 是在什么条件下算出来的」。
2. **结论层（F 类）**：报告是 12 个中间指标小节的堆叠，**没有一句话的结论**。
   而项目自己的 L2 判据里就有「评级」、L3 判据四项稳健性 —— **报告一项都没有**。
3. **研报标准三件套（C/E 类）**：超额收益体系、Top-N 持仓收缩、风格相关性 ——
   API 代码里注释直接写着「研报标准三件套」，**三件全部不在报告里**。

**最关键的一点**：上面这些**平台几乎全都已经算好了**。同一份评价在 Web 上会渲染
评级面板、稳健性面板、预处理配方、超额净值曲线、Top-N 表、风格相关性、中性化归因阶梯、
市值分组 IC、滚动窗口 IR —— **报告里一个都没有**。
报告是唯一会离开平台的产物（要邮件发出、要归档），却是**所有视图里最贫的一个**。

## 四、一句话诊断

**报告的问题不是「内容不够多」，而是「内容层级不完整」**：

- 它覆盖了 **「因子有没有效」**（IC、分层、衰减、换手、成本）—— 这条线做得相当扎实，
  甚至比 alphalens 默认 tear sheet 更细（有成本敏感性、事件式、NW t 值）。
- 它完全缺失 **「这个因子是在什么条件下算出来的」**（A 类）——
  而项目自己的头号关切正是「默认中性化是静默假动作」（方案 §1.1）。
- 它完全缺失 **「所以到底能不能用」**（F 类）—— 而 L2/L3 判据全在这一类。

一份**只有过程指标、没有前提条件、没有结论**的报告，归档三个月后基本无法复读：
读者不知道该不该信那个 IC，也不知道它是在什么配方、什么样本上跑出来的。
